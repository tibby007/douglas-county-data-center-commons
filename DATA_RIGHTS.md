# Data rights

The demo distributes original index entries, links, and provenance. The county agenda and attachments remain with their issuers. County documents, logos, maps, plans, and vendor materials are outside the scope of the project licenses.

| Material | License and scope |
| --- | --- |
| Original project code | [Apache-2.0](LICENSE) |
| Original factual index contributions where the project holds rights | [CC0 1.0](LICENSE-DATA). Cite the index and the original record as a courtesy. |
| Original guide and methodology | [CC BY 4.0](LICENSE-METHOD). Credit Douglas County Data Center Commons, link to the source and license, and indicate changes. |
| Fonts, icons, and bundled libraries | Each dependency retains its own license. See [dependency notices](docs/dependency-notices/). |
| Illustrative landscape | AI-generated for the demo. It depicts no identified site and is outside the scope of the code, data, and methodology licenses. |

The [source register](docs/SOURCES.md) records inclusion and reuse decisions per source. Keep whole county documents outside the project unless the project owner confirms reuse rights. Keep personal contact details, signatures, private correspondence, and sensitive layouts out of the index.
