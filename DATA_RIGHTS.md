# Data rights

The demo distributes original index entries, links, and provenance. The county agenda and county attachments are linked or listed in the source register. The demo contains no copies of those documents. Third-party documents, logos, maps, plans, and vendor materials are excluded from project license proposals.

| Material | Proposed treatment |
| --- | --- |
| Original project code | Apache-2.0, subject to owner approval |
| Original factual-index contributions where rights allow | CC0-1.0, subject to owner approval |
| Original guide and methodology | CC BY 4.0 if approved by the owner |
| Fonts, icons, and bundled libraries | Each dependency retains its own license. See [dependency notices](docs/dependency-notices/). |
| Illustrative landscape | AI-generated for the demo. Project asset release status pending. It depicts no identified site. |

The [license texts](docs/proposed-licenses/) are included for review. Inclusion does not activate a grant or a dedication. Mozilla consultation may affect licenses for future funded work. If a CC0 dedication is approved, citing this index and the original record would be a courtesy.

The [source register](docs/SOURCES.md) records inclusion and reuse decisions per source. Keep whole county documents outside the project unless the project owner confirms reuse rights. Keep personal contact details, signatures, private correspondence, and sensitive layouts out of the index.
